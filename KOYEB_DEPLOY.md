# Инструкция: Бесплатный запуск EduControl на Koyeb (24/7 онлайн)

Проект полностью настроен для автономной работы **на одном единственном бесплатном облачном хостинге Koyeb**.
Сайт работает **24/7 (день и ночь)**, **не засыпает**, имеет **валидный HTTPS-сертификат** (камера и сканирование лиц работают на смартфонах и компьютерах) и содержит готовую базу данных преподавателей.

---

## 1. Что сделано по безопасности (Security Audit)

1. **Защита от утечек (`.gitignore`):**
   * Все секретные файлы (`.env`, `.env.*`) и база данных (`dev.db` с биометрическими данными и хешами) надёжно исключены из версионирования. Они не попадут в публичный доступ при загрузке на GitHub.
2. **Безопасная архитектура Same-Origin (Next.js Rewrites):**
   * Все обращения к API перенаправляются через внутренний прокси `/api/...`.
   * Серверный порт `5000` полностью изолирован внутри контейнера и не торчит наружу в интернет.
   * Отсутствуют проблемы CORS и Mixed Content (HTTP внутри HTTPS).
3. **Скрытие служебных заголовков:**
   * Отключены служебные заголовки `X-Powered-By: Next.js` и `X-Powered-By: Express`.
4. **Безопасные шаблоны переменных:**
   * Созданы шаблоны `.env.example` для клиента и сервера.

---

## 2. Пошаговый запуск в облаке Koyeb (3 простых шага)

### Шаг 1: Загрузить проект в ваш GitHub

1. Откройте терминал в папке проекта или используйте GitHub Desktop:
   ```bash
   git init
   git add .
   git commit -m "feat: complete secured 24/7 cloud suite for Koyeb"
   ```
2. Создайте новый репозиторий на [github.com/new](https://github.com/new) (например, `educontrol`) и опубликуйте код:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН_GITHUB/educontrol.git
   git branch -M main
   git push -u origin main
   ```
   *(Благодаря нашему `.gitignore`, никакие пароли и приватные файлы не утекут)*.

---

### Шаг 2: Создать бесплатный сервис на Koyeb

1. Перейдите на сайт [koyeb.com](https://www.koyeb.com/) и войдите через кнопку **Sign in with GitHub**.
2. В панели управления нажмите зелёную кнопку **"Create Service"** (или **"Create Web Service"**).
3. Выберите источник: **GitHub**.
4. Выберите ваш репозиторий **`educontrol`** и ветку `main`.
5. В блоке **"Builder"**:
   * Koyeb автоматически определит **`Dockerfile`**.
6. В блоке **"Instance"**:
   * Выберите тариф **Free / Eco (Nano)** — 512 MB RAM, 0.1 vCPU (*100% бесплатно навсегда*).
7. В блоке **"Regions"**:
   * Выберите ближайший регион (например, `Frankfurt (fra)`).
8. В блоке **"Port"**:
   * Убедитесь, что указан порт **`8000`** (протокол `HTTP`).
9. Введите имя приложения (например, `educontrol-demo`) и нажмите **"Deploy"**.

---

### Шаг 3: Получить ссылку и отправить клиенту

Через 2–3 минуты Koyeb соберёт проект и выдаст готовую ссылку с зелёным статусом **Healthy**:
👉 `https://educontrol-demo-ваш-логин.koyeb.app`
